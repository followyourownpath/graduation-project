# 前端设计文档：AI 驱动的房贷评分系统 (AI Powered Mortgage Scoring Engine)

## 1. 项目概述
AI 驱动的房贷评分系统是一个旨在自动验证文件、加强合规性并简化房贷申请审查流程的平台。主要用户将是内部合规审查员和管理员，他们需要审查申请、验证提取的数据并评估欺诈风险。

## 2. 目标受众与角色
- **合规审查员 / 分析师 (Compliance Officer / Analyst)：** 主要用户，负责审查申请、解决 OCR 识别差异、检查欺诈预警，并做出合规性决定。
- **经纪人 / 管理员 (Broker / Admin)：** 负责创建申请和上传客户文件的用户。
*(注意：复杂的基于角色的访问控制 (RBAC) 超出了 MVP 阶段的范围，因此初期的角色差异将降至最低)。*

## 3. UI/UX 设计原则
- **专业与可信赖：** 干净、现代且以数据为中心的设计，适合金融企业级应用程序。
- **可扫描性与清晰度：** 使用清晰的颜色编码（例如，红色表示高风险，琥珀色表示警告，绿色表示已验证）突出显示关键风险指标、不匹配项和欺诈预警。
- **高效：** 布局应通过并排比较（例如，原始文件查看器旁边是提取的数据）尽量减少合规审查员的点击次数。
- **响应式：** 虽然主要是一个桌面端 Web 应用程序，但它应该优雅地处理不同的屏幕尺寸。

## 4. 核心页面与用户旅程 (MVP 范围)

### 4.1. 身份验证 (登录页面)
- **功能：** 用于 MVP 阶段的简单静态登录页面。
- **设计：** 干净的品牌标识、用户名/密码字段，以及凭据无效时的错误状态提示。

### 4.2. 仪表盘 (合规审查中心 - Dashboard)
- **功能：**
  - 所有活跃房贷申请的概览。
  - 快速指标：总申请数、待审查数、高风险申请数。
  - 列出申请的数据表格，包含以下列：申请人姓名、贷款类型、提交日期、状态以及**整体风险评分**。
  - 过滤和排序（按风险类别、状态、贷款类型）。

### 4.3. 申请创建与文件上传
- **功能：**
  - 创建新房贷申请的表单。
  - 选择“贷款类型”（这决定了所需的文件清单）。
  - 批量文件上传界面（支持 PDF、JPG、PNG 的拖放）。
  - 实时上传状态和文件验证（大小、类型）。

### 4.4. 申请详情与审查页面 (核心界面)
这是审查员花费最多时间的最关键页面。
- **头部区域：** 申请人摘要（姓名、出生日期、贷款类型）和整体申请风险评分。
- **文件清单面板：** 必需文件的状态（已上传、缺失、被拒绝）。
- **OCR 与数据提取查看器 (分屏 / 并排展示)：**
  - *左侧面板：* 文件查看器（PDF/图片渲染器），用于查看上传的文件（例如，工资单）。
  - *右侧面板：* 提取的数据表单（结构化 JSON 数据以可编辑表单字段的形式呈现）。允许审查员验证并纠正低置信度的提取结果。
- **跨文件一致性与欺诈预警面板：**
  - 突出显示不匹配项（例如，“工资单收入与银行对账单存款不符”）。
  - 显示欺诈指标（例如，“在身份证件上检测到可疑元数据”）。
  - 基于规则的合规性标记。
- **操作栏：** 用于对申请进行“批准 (Approve)”、“标记以供审查 (Flag for Review)”或“拒绝 (Reject)”的按钮，以及备注/审计日志部分。

## 5. 技术栈推荐
- **框架：** React.js（推荐使用 Next.js 或 Vite 快速搭建）或 Vue.js。
- **样式：** 使用 Tailwind CSS 进行快速、一致的样式设计，或使用 MUI / Ant Design 等组件库来实现企业级数据表格和表单。
- **文档查看：** react-pdf 或类似库，用于在浏览器中原生渲染 PDF。
- **状态管理：** Zustand, Redux, 或 React Context（取决于复杂度）。
- **API 通信：** 使用 Axios 或 Fetch API 与 Python/.NET/Node.js 后端进行通信。
